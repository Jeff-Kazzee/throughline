# Workspaces

A workspace owns its live truth.

Throughline owns reusable method. Project, content, research, and private-memory folders own their current facts.

## Boundary Rules

- Link to workspace truth instead of duplicating everything.
- Keep dependencies inside the owning project.
- Keep private overlays out of public templates.
- Promote only reusable lessons into Agent OS docs.
- Prefer Obsidian or a similar visible tool for project state when the user benefits from a visual workspace.
- If HTML updates are enabled, write them where the user can open them quickly without loading the whole context history.
