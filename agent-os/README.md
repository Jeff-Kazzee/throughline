# Agent OS

This folder holds the reusable method layer for a Throughline workspace.

## Layers

- **Personas**: orchestrator and sub-agent role contracts.
- **Retrieval**: search, query, update, and context loading rules.
- **Quality**: checks, review gates, and provenance.
- **Trust**: visible plans, evidence, human gates, and run logs.
- **Workspaces**: boundaries between projects, content, research, and private memory.
- **Knowledge**: source ledgers, credits, and source-intake rules.

## Operating Rule

Small always-on context. Rich on-demand context. Private memory stays private.
