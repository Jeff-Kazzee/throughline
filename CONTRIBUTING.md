# Contributing

Throughline is intentionally small. Contributions should make agent work clearer, safer, or easier to verify.

## Principles

- Keep public docs generic.
- Keep private memory out of git.
- Prefer concise procedures over long philosophy.
- Add sources for borrowed ideas.
- Do not turn project-specific practice into a universal rule without evidence.
- Hooks are specs until explicitly wired.

## Good Contributions

- clearer first-run interviews
- better privacy gates
- source-ledger improvements
- concise persona contracts
- useful command specs
- lightweight quality checks
- examples that do not expose private data

## Avoid

- giant prompts
- raw transcripts in always-on docs
- tool-specific lock-in
- hardcoded user names
- secret or credential examples
- brittle automation that hides what it is doing
