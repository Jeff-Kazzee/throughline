# write-day-end-update

Use this command to create a visible HTML update at the user's chosen cadence.

## Prompt

```md
Create a day-end update.

Visible state surface:
Run log:
Update cadence:
Output path:
Audience: private | team | public

Summarize outcomes, decisions, checks, blockers, next actions, and privacy notes.
Do not include secrets, private names, private memory, or sensitive excerpts unless explicitly approved.
Use `docs/templates/day-end-update.html` as the default structure.
```

## Output

- HTML update path.
- Sources used.
- Privacy check result.
- Next actions.
