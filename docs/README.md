# Throughline Documentation

Throughline is an Agent OS for human-led AI work. It gives agents a working structure without asking the human to surrender control of the project, the memory, or the final judgment.

The framework is intentionally small. It is made of Markdown files, private local templates, agent instructions, command specs, hook specs, and source-led operating rules. That smallness is a feature. A good agent system should be easy to inspect before it becomes powerful.

## Start Here

Read [getting-started.md](getting-started.md) if you want to install Throughline into a personal workspace or project.

Read [framework.md](framework.md) if you want to understand the system model: what each layer does, how the pieces fit together, and where future retrieval, dashboard, and orchestration work belongs.

Use [templates/](templates/) when you want a concrete starting point for user interviews, workspace adapters, run logs, source ledgers, or day-end updates.

## Documentation Map

- [getting-started.md](getting-started.md) explains the first setup flow.
- [framework.md](framework.md) explains the operating model.
- [templates/](templates/) contains reusable public templates.
- [sources/credits.md](sources/credits.md) records public inspiration and source credits.

Private memory, product planning, and unpublished website work do not belong in this folder. Keep those in ignored local files.
