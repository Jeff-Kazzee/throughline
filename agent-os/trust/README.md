# Trust

Trust comes from visible work, evidence, and gates.

## Visible Surfaces

- task contract
- plan
- current status
- source trail
- loaded context
- checks run
- decisions made
- human gates
- handoff
- daily or session-end HTML update, if enabled

## Human Gates

Pause before:

- publishing private material
- indexing secrets or sensitive memory
- changing global rules
- initializing git or pushing public
- installing dependencies
- using external tools with unclear data sensitivity
- turning a project-specific lesson into framework guidance

## Update Cadence

Ask the user which cadence they want:

- daily
- session-end
- milestone
- manual only
- disabled

When enabled, generate a concise HTML update from the run log and visible state surface. The HTML should summarize outcomes, decisions, blockers, checks, and next actions without exposing private data.
