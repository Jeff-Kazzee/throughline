02 / 07 · the problem

Agents lose the plot.

Your intent, your sources, your decisions: they live inside a chat window. Close it, and they are gone. The next session, or the next agent, starts from nothing.

signal lost

03 / 07 · the loop

Ask. Retrieve. Act.
Verify. Learn. Update.

Throughline runs every session through the same six steps, in the open. It starts by interviewing you, so the work begins from what you actually want.

  1. Askintent It interviews you first, so the work starts from what you want, not a guess.
  2. Retrievesources It pulls the sources that matter and keeps a link back to each one.
  3. Actchanges It does the work where you can watch it happen, not inside a black box.
  4. Verifychecks Quality gates run before any work is allowed to count as done.
  5. Learnnotes It records what changed, and why, so the lesson is not lost next time.
  6. Updatehandoff Every session ends with a written next step for whoever picks it up.

04 / 07 · what it keeps

What it keeps between sessions.

  1. Private memory Your personal context stays in local files that never get committed or shared. local only
  2. Visible state The current state of the project lives somewhere you can open and read.
  3. Source trail Every claim and change links back to the source it came from.
  4. Quality gates Checks the work has to pass before it is allowed to count as done.
  5. Handoff Every session ends with evidence, decisions, and a clear next step.
