# Source Intake

Use this when the user drops a file, article, transcript, repo, or document for agents to learn from.

## Intake Contract

Before processing, identify:

- source path or URL
- what the user wants from it
- sensitivity
- affected workspace
- whether to summarize, critique, compare, index, or extract tasks

## Distillation Rules

- Preserve the source pointer.
- Keep quotes short.
- Separate fact, inference, and recommendation.
- Remove transcript drift and duplicate framing.
- Promote only reusable lessons into framework docs.

## Human Gates

Ask before:

- publishing private material
- deleting raw source
- indexing sensitive material
- applying one project rule globally
