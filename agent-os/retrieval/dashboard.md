# Dashboard Model

A Throughline dashboard should make agent context visible to the user.

First version should be read-only.

## Views

- Domain registry.
- Source ledger.
- Context queue.
- Loaded context.
- Human gates.
- Update proposals.
- Run log.
- Quality checks.
- Drift and staleness.
- Learning trace.
- Daily or session-end HTML updates.

## Questions It Should Answer

- What can the agent search?
- What did the agent actually load?
- What is private or sensitive?
- What source supports this claim?
- What update is waiting for approval?
- What index or source is stale?
- What changed since the last visible update?
