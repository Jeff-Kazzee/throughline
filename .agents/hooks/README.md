# Hooks

These are hook specs, not active automation.

## Starter Hooks

- `pre-install`: warn before dependency installs outside the owning project.
- `pre-subagent-batch`: require orchestrator task contracts before sub-agents launch.
- `pre-public-export`: check for private names, secrets, machine paths, and missing source credits.
- `pre-global-promotion`: require evidence before project-specific lessons become framework rules.
- `source-drop-detected`: remind the agent to ledger, classify, and distill source material.
- `post-run-learning`: suggest a learning record after meaningful work or repeated failure.
- `post-session-update`: if enabled, create a concise HTML update for the chosen visible state surface.

## Rules

- Keep hooks visible.
- Prefer warnings before hard blocks.
- Do not log private data.
- Do not enable active hooks without explicit approval.
